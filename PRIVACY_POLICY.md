# Privacy Policy

Last updated: 2026-05-26

App Invisivel is a privacy and device security application. This Privacy Policy explains how the app handles information when you use the application.

## Summary

- App Invisivel does not sell personal data.
- App Invisivel does not use third-party advertising SDKs.
- App Invisivel does not use third-party analytics or behavioral tracking SDKs.
- The app's security checks are designed to run locally on the device whenever possible.

## Information Handling

App Invisivel may process device and network-related information locally on the device to provide security features such as:

- device integrity and risk checks
- local security configuration
- connectivity and network state checks
- privacy and protection status inside the app

This processing is used to operate the app's security features and improve the user's protection experience inside the app.

## Data Collection

At this stage of the product, App Invisivel is designed to avoid unnecessary collection of personal information. The app does not require account creation to use the review build submitted to App Store Connect.

If future versions introduce online services that collect user data, this Privacy Policy will be updated before those changes are released.

## Data Sharing

App Invisivel does not sell user data to third parties.

## Data Retention

Any app state stored by the app is intended to remain on the user's device unless the user removes the app or clears local data.

## Security

App Invisivel is built around privacy and security principles, including local protections and encrypted handling where applicable.
